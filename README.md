 NEWS EXPLORER 
 News Explorer is a searchable news repository designed to efficiently store, organize, retrieve, and explore a large collection of news articles. The main purpose of the project is to help users quickly find relevant news without manually going through thousands of articles.

The system will allow users to enter keywords, phrases, or topics and retrieve matching articles from the repository. It will also support fuzzy search, so users can still receive relevant results when they make spelling mistakes in their queries. Articles will be organized into categories such as Technology, Sports, Politics, Business, and Entertainment, making topic-based browsing easier.

Another important feature is related-news recommendation, where the system identifies articles with similar content and suggests them to the user. To make these operations efficient, the project will apply DSA concepts such as KMP, Rabin-Karp, hashing, tries, and dynamic programming. These techniques are particularly relevant to the DSA-3 handout's emphasis on pattern searching, fuzzy matching, and document similarity.
